# تطبيق الخريطة الإعلانية – مدينة قنا الجديدة (أندرويد)

التطبيق عبارة عن الخريطة التفاعلية (`www/index.html`) ملفوفة بـ Capacitor، وكل الملفات (Leaflet والبيانات) جوّا التطبيق.
خرائط الأساس بتتحمّل من الإنترنت.

## الطريقة ١: بناء الـ APK بدون تثبيت أي برامج (GitHub)
1. اعمل حساب مجاني على github.com وأنشئ Repository جديد (Private لو عايز).
2. ارفع محتويات المجلد ده كلها (بما فيها المجلد المخفي `.github`) على الـ Repository.
3. افتح تبويب **Actions** ← **Build APK** ← **Run workflow**. استنى 5–8 دقايق.
4. افتح التشغيل اللي خلص، ونزّل الملف من **Artifacts** (`qena-ads-map-apk`)، فُك الضغط وهتلاقي `app-debug.apk`.
5. انقل الملف للموبايل وافتحه (فعّل "التثبيت من مصادر غير معروفة" لو طلب).

## الطريقة ٢: بالكمبيوتر (Android Studio)
المطلوب: Node.js 20 و Android Studio.
```
npm install
npx cap add android
npx cap sync android
npx cap open android
```
ومن Android Studio: **Build ← Build APK(s)**.

## الطريقة ٣: بدون APK (PWA)
ارفع مجلد `www` على أي استضافة HTTPS، وافتح الرابط من Chrome في الموبايل ← القائمة ← **Add to Home screen**.

## تحديث البيانات
عدّل `www/index.html` (مصفوفة `DATA`) أو ابعتلي الجيوداتابيز الجديدة وأنا أطلعلك النسخة المحدّثة، وبعدها أعد البناء.
